# Yechen Wang Portfolio — Live Editable Prototype

This version is intentionally designed for **visual-first iteration**.

## Open it

Double-click `index.html` and open it in Chrome/Edge/Safari.

No npm install or build step is required.

## Live edit mode

Click **Edit content** in the top-right corner.

- Editable text will be highlighted.
- Click any highlighted text and type directly on the page.
- Changes save automatically to your browser using `localStorage`.
- Refreshing the page keeps your edits.
- `Export content` downloads your current copy as JSON.
- `Reset` restores the initial demo copy.

This is meant to help settle the visual direction before locking in final portfolio content.

## Theme

Use the circle icon in the top-right corner to switch between light and dark themes.

## Important note about “real-time sync”

This prototype provides **instant live editing in the browser** and keeps edits on the same browser/device.

For true cross-device or online content sync, the next step is to connect the site to something like a lightweight CMS/backend (for example Supabase, Sanity, Contentful, or a Git-based workflow) and deploy it online.
